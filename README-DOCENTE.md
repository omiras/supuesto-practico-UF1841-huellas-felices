# Preparación del ejercicio

- Entregar al alumnado la carpeta `alumnado`, `ENUNCIADO.md` y las dos imágenes de referencia.
- Conservar `RUBRICA.md` para la corrección si no se desea mostrar la puntuación detallada de antemano.
- El alumnado construye todo el HTML, añade las clases y escribe el CSS general dentro de `<style>`. Después puede pegar el `index.html` completo directamente en Moodle.
- `formulario.css` contiene exclusivamente los estilos ya facilitados del formulario.
- La solución completa está separada en la carpeta `solucion-docente`.
- La carpeta `images` contiene tres imágenes de animales y el patrón claro `animal-pattern-50.png`, preparado para repetirse a `50px`; la cuarta imagen se carga mediante una URL externa.
- `servicio-contacto` es un proyecto Express independiente, preparado para GitHub y Render.

La carpeta del alumnado contiene únicamente la plantilla mínima y los estilos de ayuda del formulario; no incluye el HTML ni los estilos generales resueltos.
